## Проект для работы с базой данных PostgreSQL, содержащей сведения о работодателях и открытых у них вакансиях

### Установленные зависимости:
#### flake8 (>=7.2.0,<8.0.0),
#### isort (>=6.0.1,<7.0.0),
#### mypy (>=1.15.0,<2.0.0),
#### requests (>=2.32.3,<3.0.0),
#### psycopg2 (>=2.9.10,<3.0.0),
#### python-dotenv (>=1.1.0,<2.0.0)

### Функциональные возможности проекта:

#### 1. Выполняется создание базы данных по наименованию, введенному пользователем
##### Дополнительные возможности:
###### 1.1. Выполняется проверка существования базы с введенным названием
###### 1.2. В случае подтверждения пользователем существующая база удаляется
###### 1.3. При отказе от удаления производится переход к вводу названия

#### 2. Выполняется загрузка в базу данных сведений о работодателях и открытых у них вакансиях из сервиса api.hh.ru
##### 2.1. Возможные неудобства:
###### 2.1.1. Ориентировочное время загрузки данных из сервиса api.hh.ru - 8 минут (при средней скорости соединения)
###### 2.1.2. В зависимости от времени суток на стороне сервиса могут возникать сбои, приводящие к ошибке 403 (Доступ запрещен)
##### 2.2. Дополнительные возможности:
###### 2.2.1. Реализована возможность заполнения таблиц в базе данных с помощью фикстур, полученных ранее из сервиса по аналогичным параметрам

#### 3. Установлены базовые типы взаимодействия с базой данных:
##### 3.1. Получение списка всех компаний и количество вакансий у каждой компании
##### 3.2. Получение список всех вакансий с указанием названия компании, названия вакансии и зарплаты и ссылки на вакансию
##### 3.3. Получение средней зарплаты по вакансиям.
##### 3.4. Получение списка всех вакансий, у которых зарплата выше средней по всем вакансиям.
##### 3.5. Получение списка всех вакансий, в названии которых содержатся заданные пользователем слова

#### 4. Реализованы дополнительные возможности для работы с базой данных:
##### 4.1. Задано сохранение результатов запросов в соответствующие файлы формата .csv
##### 4.2. Реализована возможность выбора пользователем полного или облегченного режима вывода списка вакансий
